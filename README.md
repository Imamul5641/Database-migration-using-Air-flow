
# Database Migration Using Apache Airflow

This repository provides a complete guide and working example for performing **database migration using Apache Airflow**, including:

- Installing PostgreSQL  
- Creating databases, schemas, and tables  
- Loading XML data into PostgreSQL  
- Installing Airflow with PostgreSQL backend  
- Example ETL workflow for database migration  

---

# 🚀 Project Overview

Database migration is a critical step when transferring data between systems or upgrading infrastructure.  
This project demonstrates how **Apache Airflow** can orchestrate:

- Data extraction (XML file)  
- Data transformation (XML → PostgreSQL rows)  
- Data loading into PostgreSQL (ETL workflow)  

This repository is intended for engineers learning **Airflow-based data pipelines**.
