
# 4️⃣ Configure PostgreSQL for Airflow
# ------------------------------------

## Inside PostgreSQL:

```sql
CREATE DATABASE airflow_db;
CREATE USER airflow_user WITH PASSWORD 'airflow_pass';
GRANT ALL PRIVILEGES ON DATABASE airflow_db TO airflow_user;
GRANT ALL ON SCHEMA public TO airflow_user;
```
Here we are creating airflow_user as airflow will create a lot of its own tables (like DAG runs, task instances, logs), so mixing it into another app’s DB can get messy.

We Shall create a new user so that our database does not conflict with the main user and give the permission
```sql
CREATE DATABASE my_db;
CREATE USER my_user WITH PASSWORD 'my_pass'; // Here my_user and my_pass shall be decided by you to create a user
GRANT ALL PRIVILEGES ON DATABASE my_db TO my_user;
GRANT ALL ON SCHEMA public TO my_user;
GRANT USAGE ON SCHEMA my_schema TO my_user; // Here you are granting permission to use schema created by you
GRANT SELECT ON ALL TABLES IN SCHEMA school TO my_user;
```

## Update Airflow config:

```
sql_alchemy_conn = postgresql+psycopg2://airflow_user:airflow_pass@localhost:5432/airflow_db
```
