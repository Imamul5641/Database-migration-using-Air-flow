
# 3️⃣ Install Apache Airflow (with PostgreSQL)
# ------------------------------------

Install dependencies:

```bash
sudo apt install python3.8-venv libpq-dev
```

Create virtual environment:

```bash
python3 -m venv myvenv
source myvenv/bin/activate
```

Install Airflow:

```bash
pip install "apache-airflow[amazon]==2.8.0" \
  --constraint "https://raw.githubusercontent.com/apache/airflow/constraints-2.8.0/constraints-3.8.txt"
```

Install PostgreSQL Airflow provider:

```bash
pip install apache-airflow-providers-postgres
```

Initialize database:

```bash
airflow db init
```

Create user:

```bash
airflow users create \
  -u airflow \
  -f airflow \
  -l airflow \
  -r Admin \
  -e airflow@gmail.com
```

Start Airflow:

```bash
airflow webserver &
airflow scheduler
```
